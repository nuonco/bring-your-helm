# Bring Your Helm

AI-powered Helm chart to Nuon BYOC configuration generator.

Paste a GitHub URL to your Helm chart and get a complete Nuon app configuration generated by Claude.

## Local Development

**Prerequisites:** [uv](https://docs.astral.sh/uv/getting-started/installation/) (Python package manager)

```bash
# Clone the repo
git clone https://github.com/nuonco/bring-your-helm.git
cd bring-your-helm

# Install dependencies
uv sync

# Set API keys
export ANTHROPIC_API_KEY="sk-ant-..."       # required
export GITHUB_TOKEN="ghp_..."               # optional, avoids GitHub rate limits

# Run the dev server
uv run uvicorn app.main:app --reload
```

Open http://localhost:8000

### Getting API Keys

- **Anthropic API key**: https://console.anthropic.com/settings/keys
- **GitHub token** (optional but recommended): https://github.com/settings/tokens — create a fine-grained token with "Public repositories (read-only)" access. Without this you're limited to 60 GitHub API requests/hour.

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `ANTHROPIC_API_KEY` | Yes | Anthropic API key for Claude |
| `GITHUB_TOKEN` | No | GitHub token for higher API rate limits (60/hr → 5,000/hr) |
| `CLAUDE_MODEL` | No | Claude model to use (default: `claude-sonnet-4-5-20250929`) |

## How It Works

1. User pastes a GitHub URL pointing to a Helm chart (e.g., `https://github.com/bitnami/charts/tree/main/bitnami/keycloak`)
2. Server fetches `Chart.yaml` and `values.yaml` via the GitHub API
3. Server sends the chart context to Claude with a specialized system prompt that knows Nuon's TOML config format
4. Claude generates a complete app configuration: `metadata.toml`, `inputs.toml`, component files, templated values, and actions
5. Results are displayed as collapsible file cards with copy and download buttons

## Deployment

Deployed to [Render](https://render.com) as a web service. Pushes to `main` auto-deploy.

- **Build command**: `uv sync --frozen && uv cache prune --ci`
- **Start command**: `uv run uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- **Environment variables**: Set `ANTHROPIC_API_KEY` and optionally `GITHUB_TOKEN` in Render's Environment settings
