# Bring Your Helm

AI-powered Helm chart to Nuon BYOC configuration generator.

Search for any Helm chart on GitHub or ArtifactHub, pick the chart you want, and get a complete Nuon app configuration generated by Claude.

## Local Development

**Prerequisites:** [uv](https://docs.astral.sh/uv/getting-started/installation/) (Python package manager)

```bash
# Clone the repo
git clone https://github.com/nuonco/bring-your-helm.git
cd bring-your-helm

# Install dependencies
uv sync

# Set API keys
export ANTHROPIC_API_KEY="sk-ant-..."       # required
export GITHUB_TOKEN="ghp_..."               # optional, avoids GitHub rate limits

# Run the dev server
uv run uvicorn app.main:app --reload
```

Open http://localhost:8000

### Getting API Keys

- **Anthropic API key**: https://console.anthropic.com/settings/keys
- **GitHub token** (optional but recommended): https://github.com/settings/tokens — create a fine-grained token with "Public repositories (read-only)" access. Without this you're limited to 60 GitHub API requests/hour.

## How It Works

1. **Search** — Type a name (e.g. "signoz") or paste a GitHub URL. Search queries are proxied through the backend to use your GitHub token and avoid CORS.
2. **Pick a chart** — After selecting a repo, the app scans for all `Chart.yaml` files using GitHub's Trees API. If only one chart is found, it's auto-selected.
3. **Configure + Generate** — Optional guidance text and advanced options (cloud provider, infra mode) are combined and sent to Claude along with the chart's `Chart.yaml` and `values.yaml`.
4. **Download** — Results appear as collapsible file cards. Download individual files or grab everything as a ZIP.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Landing page with wizard UI |
| `GET` | `/api/search?q=...` | Search GitHub repos (or parse a direct URL) |
| `GET` | `/api/search/artifacthub?q=...` | Search ArtifactHub for Helm charts |
| `POST` | `/api/discover` | Discover charts in a repo (form fields: `org`, `repo`, `branch`) |
| `POST` | `/analyze` | Generate Nuon config (form fields: `repo_url`, `guidance`) |

## Caching

Generated configs are cached in-memory for 1 hour, keyed by `org/repo@branch:directory`. Caching only applies when no custom guidance is provided (custom guidance makes each request unique). Cached responses include a `"cached": true` flag, and the UI shows a "cached" badge.

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `ANTHROPIC_API_KEY` | Yes | Anthropic API key for Claude |
| `GITHUB_TOKEN` | No | GitHub token for higher API rate limits (60/hr → 5,000/hr) |
| `CLAUDE_MODEL` | No | Claude model to use (default: `claude-sonnet-4-5-20250929`) |


## Deployment

Deployed to [Render](https://render.com) as a web service. Pushes to `main` auto-deploy.

- **Build command**: `uv sync --frozen && uv cache prune --ci`
- **Start command**: `uv run uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- **Environment variables**: Set `ANTHROPIC_API_KEY` and optionally `GITHUB_TOKEN` in Render's Environment settings
