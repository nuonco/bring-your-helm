# Bring Your Helm

AI-powered Helm chart to Nuon BYOC configuration generator.

Paste a GitHub URL to your Helm chart and get a complete Nuon app configuration generated by Claude.

## Setup

```bash
uv sync
ANTHROPIC_API_KEY=sk-... uv run uvicorn app.main:app --reload
```

Open http://localhost:8000

## Environment Variables

- `ANTHROPIC_API_KEY` (required) — Anthropic API key for Claude
- `GITHUB_TOKEN` (optional) — GitHub token for higher API rate limits
- `CLAUDE_MODEL` (optional) — Claude model to use (default: claude-sonnet-4-5-20250929)
