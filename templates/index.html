What to do with these files

1. Create a git repository for your app config

Nuon app configurations live in a git repository. Create a new directory named after your app (the directory name must match your Nuon app name): 

mkdir my-app && cd my-app
git init

2. Save the generated files

Use the "Download all as ZIP" button or copy individual files into your app directory. Maintain the directory structure shown in the filenames: 

my-app/
  metadata.toml
  inputs.toml
  components/
    1-my-chart.toml
    values/
      my-chart/
        values.yaml

3. Review and customize

The AI-generated config is a strong starting point, but you should review it:

  • Check inputs.toml — are the right values exposed as customer inputs?
  • Check the values file — are template variables wired correctly?
  • Add sandbox.toml, runner.toml, and permissions/ if not generated (see docs)

4. Create your app and sync

Use the Nuon CLI to create your app in the control plane and sync the config: 

nuon apps create -n my-app
nuon apps sync

5. Validate

After syncing, validate your configuration to catch any issues before deployment: 

nuon apps validate

For the full configuration file reference, see the Nuon configuration docs.
